# Product Specification: Signet

> **Chat is the spine.**

Signet is a multi-tenant chat app for Greek-letter organizations in which every other capability — events, tasks, dues, points, polls — is a *chat integration*, surfaced inline in the conversation rather than parked behind its own nav tab. Chat is free, unlimited, and non-optional; a flat per-chapter subscription unlocks the ops integrations and the AI features.

This file's title and tagline used to name Frapp and quote "The Operating System for Greek Life", above the same "replaces Discord, OmegaFi, Life360" sentence the root `README.md` also carried. That framing predates the chat-first inversion and contradicted [`positioning.md`](positioning.md) — this file's own first topic. Corrected 2026-09-22 in [#2465](https://github.com/pdcarlson/Frapp/issues/2465), which rewrote the root README in the same change.
