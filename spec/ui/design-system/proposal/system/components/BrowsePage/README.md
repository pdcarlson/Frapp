A page for finding one of many: the list from the first line, in groups.

**Status:** Proposed. Drawn for Events beside today's capture.

| | Built from |
| --- | --- |
| Web | Page header, Segmented and filters, New button, Raised group, Section header, List row |
| Phone | `ScreenShell`, the header button, the same groups, the floating plus |

## Skeleton

1. **Header:** the title, the view switch, search, Filter, More, New.
2. **For a list by day:** a week strip in a raised group. Each day shows its number and a dot per event; today wears the accent tint. It is the only calendar on the agenda.
3. **Groups:** one per day under a written-out heading ("Today", "Tomorrow", "Sunday, November 22"), or one per kind. One row per item.
4. **An empty day** that matters (today) keeps its group with one fact line.

## Rules

- One column. The month is a view under the switch, or the aside when the page is wide; it is never half the page.
- One kind of row on the page.
- No link or button on a group's heading beyond one quiet action at its trailing edge.
- The same page on the phone, with the same name.
- Used by Events, Tasks, Meetings, Documents, Directory, Backwork, Notifications, Messages and Chat home.

## You provide

The views, the filters, the groups and their rows.
