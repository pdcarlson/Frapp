Six page types. Every route is one of them, on both apps, and the type fixes the skeleton.
1. Standing
Where do I stand? Opens on one figure, then your own items, then the chapter's.
Activity · Points · Service hours · Study hours · Dues · You
2. Browse
Find one of many. Opens on the list itself, grouped by day or kind.
Events · Tasks · Meetings · Documents · Directory · Backwork · Notifications · Messages
3. Record
One thing. Its state, its next step, its properties, what it holds, who, history.
An event · a task · a set of minutes · a member · a document · a role
4. Form
Make a thing. A borderless title, property rows, one commit.
New event · New task · Log service · Invite members · Adjust points
5. Settings
Change how it works. Sections, grouped rows, saved as they change.
Chapter settings · Roles and groups · your Settings
6. Conversation
Talk. Messages from the bottom up, the composer pinned.
A channel · a direct message · Ask Frapp
1One column. A page is a single column, at most 720 wide, starting at the title's left edge. No columns inside a page.
2One aside, only when wide. With chat closed and room to spare, context (the month, the standings) may sit beside the column. It drops under it when narrow and on the phone.
3The same skeleton on the phone. Same groups, same order, same words.
