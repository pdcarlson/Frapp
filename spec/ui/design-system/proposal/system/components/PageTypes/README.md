The six page types every screen is built from.

**Status:** Proposed. See Screen layouts for the reasoning and the route table.

| Type | Opens on | Then |
| --- | --- | --- |
| Standing | One figure | To review (officers), yours, the chapter's |
| Browse | The list itself | Groups by day or kind |
| Record | Its state and next step | Properties, contents, people, history |
| Form | A borderless title | Property rows, one commit |
| Settings | Sections | Grouped rows, saved as they change |
| Conversation | The latest messages | The composer, pinned |

## Rules

- Pick the type before drawing anything. A screen that fits none is two screens.
- One column, at most 720 wide, from the title's left edge. No columns inside a page.
- One aside for context only when the page is wider than about 1100; it drops under the column when narrow and on the phone.
- The same type, groups, order, words and name on both apps.
- A row has one control.
