1sChat first-paint contract · fixes the ~5s cold load
0 ms · SSR
Nav, top bar, chapter name, channel column chrome, composer shell. Static markup in the RSC payload; no client query gates it. Sidebar collapsed state read from a cookie so there is no flip.
first chunk
Channel list + last active channel id from cache (Dexie). Rows render read-styled with no badges rather than waiting for counts. Last ~30 messages of the active channel from the same cache render real; the rest of the window is skeleton with reserved geometry.
blocks paint
Nothing but shell + cached channel + cached tail. If cache is cold: shell + skeleton at 300ms, real rows on the first message response.
after paint
Unread counts → member names → notification level → presence → categories → bookmarks, pins → notification badge → search index. Each fills into space already reserved. Categories regroup only below the fold or on next visit.
split
shell chunk: layout, nav, top bar, find. chat chunk: timeline (virtualized), composer, renderers. chat-extras lazy: emoji picker, slash palette, thread panel, Ask drawer, mention list.
delete
The categoriesQuery.isPending gate on the whole shell; the shell-level LoadingState card; refetch-on-mount for channels when a cached list exists.
budget
Shell visible ≤ 200ms · cached channel readable ≤ 400ms · composer focusable ≤ 400ms · zero CLS above the composer.
