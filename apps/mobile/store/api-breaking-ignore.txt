# Breaking API changes the shipped-contract check waives, passed to oasdiff's --err-ignore
# by scripts/check-api-breaking-changes.mjs --shipped.
#
# Lines starting with # are removed before oasdiff reads the file. Waive only a change no
# shipped binary depends on (a web-only route), with the reason and the evidence on the
# comment line above the entry. Format, and when an entry may go:
# apps/mobile/store/README.md, section "Shipped builds and the API contract".

# #3485 limits role `color` to the palette. Only the web Roles page writes roles: at both shipped
# SHAs (android 0.9.0+2 at ea9bc12c; ios 0.9.1+8 and android 0.9.1+3 at cca52dec),
# `git grep 'useCreateRole\|useUpdateRole' <sha> -- apps/mobile` finds no caller,
# so the binaries never send POST /v1/roles or PATCH /v1/roles/{id} (the hooks they bundle from
# packages/hooks define them, unused).
POST /v1/roles request property 'color' was restricted to a list of enum values
PATCH /v1/roles/{id} request property 'color' was restricted to a list of enum values

# #3708 deletes the .ics export. Only the web dashboard called GET /v1/events/{id}/ics (through
# useDownloadEventIcs); mobile built its .ics locally in apps/mobile/lib/calendar-export.ts. At
# every shipped SHA (ea9bc12c, cca52dec, 5e43a27b, 55922eab, 728fb69e, b61c20c3, 547c1364),
# `git grep 'useDownloadEventIcs\|/ics"' <sha> -- apps/mobile` finds no caller, so the binaries
# never request the route (the hook they bundle from packages/hooks defines it, unused).
GET /v1/events/{id}/ics api path removed without deprecation

# #4075 folds custom roles into ordinary roles and deletes their writes. Only the web Settings page
# created, edited or deleted a custom role. At every shipped SHA (ea9bc12c, cca52dec, 5e43a27b,
# 55922eab, 108b7ac7, 728fb69e, b61c20c3, c91ec8d8, 547c1364, 68a47019),
# `git grep 'useCreateCustomRole\|useUpdateCustomRole\|useDeleteCustomRole' <sha> -- apps/mobile`
# finds no caller (the hooks they bundle from packages/hooks define them, unused). The binaries do
# call GET /v1/custom-roles (useCustomRoles in the member sheet), so that route stays, answering [].
POST /v1/custom-roles api removed without deprecation
DELETE /v1/custom-roles/{id} api path removed without deprecation
PATCH /v1/custom-roles/{id} api path removed without deprecation

# #4635 moves task photos into task_photos rows and replaces #4565's single-photo fields and photo
# route. Only the web dashboard used them: #4565's phone half never shipped. At the shipped SHA
# c85e2c3a (ios 0.12.0+22, android 0.12.0+14), `git grep 'photo-url\|photo_required\|reference_photo_path\|proof_photo_path\|useTaskPhotoUrl' c85e2c3a -- apps/mobile`
# finds no caller (one hit is a comment about the chat-background photo route). The bundled
# packages/hooks reads the three fields through `nonEmptyString` / `=== true`, so their absence reads
# as no photo, and its `useTaskPhotoUrl` has no mobile caller. Earlier shipped SHAs predate #4565.
POST /v1/tasks removed the required property 'photo_required' from the response with the '201' status
POST /v1/tasks removed the required property 'proof_photo_path' from the response with the '201' status
POST /v1/tasks removed the required property 'reference_photo_path' from the response with the '201' status
GET /v1/tasks/{id}/photo-url api path removed without deprecation
