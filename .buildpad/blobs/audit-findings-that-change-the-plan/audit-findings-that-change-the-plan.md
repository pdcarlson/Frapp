# Audit findings that change the plan

(1) packages/theme + chapter-theme already exist and work \u2014 rebuild is a refactor/rename pass, not a bootstrap. (2) Mobile is a prototype: 19/23 screens hardcoded, zero modals, NativeWind configured but 0 className usages anywhere. (3) Three capabilities are actively misrepresented in the UI: QR check-in (doesn't exist anywhere), mobile study-hours/geofencing (web tells users to "use mobile app" \u2014 no such screen), mobile push toggle (no device registration behind it). (4) Event modal confirmed worst offender: 423-line flat scroll, no steps, toast-only validation after submit. (5) 11 destructive actions use browser window.confirm(). (6) Two toast systems vendored, one dead. Open decision: adopt NativeWind on mobile or commit to typed StyleSheet tokens \u2014 currently paying cost of both.
