**Verdict: don't use Gemini for the cited-answer step, but it's a real cost win for everything else around it.**

**Pricing checked for real:** Gemini 3.7 Flash is $0.75/$3.75 per M tokens (intro price thru end of 2026, doubling to $1.50/$7.50 in 2027) — actually cheaper than Claude Haiku 4.5 ($1/$5) right now, but the gap closes/reverses next year. The dramatic 20x+ savings people cite is Flash-**Lite** ($0.10/$0.40), not the capable Flash model. Cost and reliability point in opposite directions here — the cheapest tier is the least reliable one for structured output.

**Why it still doesn't fit the citation-critical step:** Gemini's citation spans point into the generated answer text, not into the source document — source identity lives one level up in a separate chunk object. That's a weaker match for "verify this quote appears verbatim in the named document" than Anthropic's design. Worse: the exact combination Signet needs — structured JSON output + grounding — is the specific mode where practitioners report grounding metadata comes back silently empty, in one report up to ~60% of calls. That's disqualifying for a citation feature regardless of price.

**Where Gemini Flash-Lite is genuinely worth using:** non-citation steps — query classification, query rewriting, reranking, casual conversational turns. None of those need verbatim citations, so none hit Gemini's weak spot. This is a well-established pattern (cheap model for pipeline plumbing, expensive model for the final grounded answer).

**Caveat before adding it:** at Signet's current scale (a few hundred users), the dollar savings are tens of dollars a month, not a make-or-break number. Adding a second provider means a second SDK and a second validation path to maintain solo. If Claude Haiku 4.5 can handle the cheap steps well enough, staying single-provider (Haiku for cheap steps, Sonnet/Fable for cited answers) is the simpler solo-dev choice — add Gemini later specifically if/when ancillary call volume grows enough that the cost gap becomes a real number.

**Net change to the decision:** still Anthropic-only for the cited answer (S1). Gemini Flash-Lite is a plausible future optimization for non-cited pipeline steps, not a broadening of the core model choice.
