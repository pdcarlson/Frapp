# Design system research

Direction shifted softer/consumer (Notion/Cash App), not technical/utilitarian — audience is students, not engineers, readability over cleverness. Still dark-first, still one restrained accent expanded via generator (Radix/Material Color Utilities) so raw chapter colors never break contrast. Adjustments from the utilitarian starting point: larger radius (12-16px default, up to 20px on chat bubbles/AI answer cards), more generous spacing and bigger touch targets (44px+ min for mobile), larger base type size (16px+ body, not 14px), humanist rounded sans font (not a mono/technical face), higher line-height for legibility, slightly warmer/lifted surface tones instead of stark near-black. Accent can show up a bit more generously than "restrained" (badges, active states, small illustrations) as long as contrast holds.
