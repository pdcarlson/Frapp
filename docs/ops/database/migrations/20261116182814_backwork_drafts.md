Adds backwork drafts (#5208): a nullable `backwork_resources.draft_fields` column, its object check, a partial index for the uploader's drafts list, and `search_backwork_resources` leaving drafts out.

## Promotion

- **Purpose**: bulk upload can save a redacted file as a draft before its fields are final. A row with `draft_fields` set is a draft, visible only to its uploader; existing rows all have it null and stay published.
- **Checks**:
  - `select count(*) from public.backwork_resources where draft_fields is not null;` returns 0 right after the push.
  - `select indexname from pg_indexes where indexname = 'idx_backwork_resources_drafts';` returns one row.
  - `select pg_get_functiondef('public.search_backwork_resources(uuid,text,integer)'::regprocedure) like '%draft_fields is null%';` returns true.
- **Promoter notes**: run before the API deploy. The new API reads and writes `draft_fields`, so an API ahead of the column 500s on every backwork list. Writes no data. Once drafts exist, the old API is not safe on this column: it doesn't filter drafts, so an API-only rollback shows every member's drafts to their whole chapter (library, single read, zip links, Activity). Clear drafts first, as in the rollback below, before rolling the API back.

## Rollback

Order matters, because only the new API leaves drafts out:

1. While the new API is still serving, remove every draft. List them with `select id, chapter_id, storage_path from public.backwork_resources where draft_fields is not null;`. Delete each one through the API's admin delete (`DELETE /v1/backwork/{id}`, which also removes its file and since #5208 reaches drafts), or delete the rows by SQL and the listed objects from the `backwork` storage bucket.
2. Roll the API back.
3. Run the forward migration below ([playbook](../../db-rollback-playbook.md#decision-matrix)). Dropping the column with a draft still in place would publish it with half-filled metadata.

```sql
-- Restore the search function from 20261109230000_backwork_courses.sql first
-- (re-run its `create or replace function public.search_backwork_resources`).
drop index if exists public.idx_backwork_resources_drafts;
alter table public.backwork_resources
  drop constraint if exists backwork_resources_draft_fields_object;
alter table public.backwork_resources drop column if exists draft_fields;
```
