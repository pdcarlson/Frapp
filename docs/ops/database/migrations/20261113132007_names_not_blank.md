A pledge class, role tier, event type or group name must have a non-whitespace character, not only pass a `btrim` that strips spaces alone (#4756).

## Promotion

- **Purpose**: Adds `chapter_pledge_classes_name_not_blank`, `role_tiers_name_not_blank`, `event_types_name_not_blank` and `chapter_groups_name_not_blank`, each `check (name ~ '[^[:space:]]')`, beside the existing length checks. Before that, any row whose name is only whitespace is renamed "Unnamed class / tier / type / group" plus the first 8 characters of its id. The API already refuses such names, so on a clean database the backfill touches nothing.
- **Checks**: Before `db push`, `select count(*) from public.chapter_pledge_classes where name !~ '[^[:space:]]';` (and the same for `role_tiers`, `event_types`, `chapter_groups`) says how many rows the backfill will rename; expect `0`. After: `select conname from pg_constraint where conname like '%_name_not_blank' order by 1;` lists the four new names (plus `roles_name_not_blank` once #4749's migration is in).
- **Promoter notes**: Independent of the API's deploy order. Writes data only for rows that would fail the check. Hosted projects are not applied from a cloud-agent session.

## Rollback

Not worth reverting: the checks refuse only names the API never writes. If one has to go, drop it in a later forward migration ([playbook § 3) Undo one migration](../../db-rollback-playbook.md#3-undo-one-migration)). A renamed row keeps its "Unnamed …" name.

```sql
alter table public.chapter_pledge_classes drop constraint if exists chapter_pledge_classes_name_not_blank;
alter table public.role_tiers drop constraint if exists role_tiers_name_not_blank;
alter table public.event_types drop constraint if exists event_types_name_not_blank;
alter table public.chapter_groups drop constraint if exists chapter_groups_name_not_blank;
```
