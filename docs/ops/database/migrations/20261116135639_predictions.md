Adds predictions, where members stake house points on chapter questions (#5133, [`spec/behavior/predictions.md`](../../../../spec/behavior/predictions.md)).

## Promotion

- **Purpose**: four new tables (`prediction_markets`, `prediction_answers`, `prediction_stakes`, `prediction_questions`), RLS on with no policies; `PREDICTION` added to the `point_transactions.category` CHECK; `chapter_points_config.prediction_max_stake` (default 25); the stake, pay and void functions; a `before delete` trigger on `chat_channels` that voids, and so refunds, the unpaid markets in a channel being deleted; `predictions:create` added to every tier (and, as an override, every role outside the tiers) that holds `polls:create`, and `predictions:manage` likewise wherever `chapter-config:manage` is held.
- **Checks**: `select count(*) from role_tiers where permissions @> array['polls:create'] and not permissions @> array['predictions:create'];` returns 0. `select pg_get_constraintdef(oid) from pg_constraint where conname = 'point_transactions_category_check';` lists `PREDICTION`.
- **Promoter notes**: apply before the API that reads it. Writes data only to `role_tiers.permissions` and `roles.permission_overrides` (additive). The category CHECK is re-added `not valid` and then validated, so the scan doesn't block points writes. The feature stays invisible until a chapter turns the `predictions` module on.

## Rollback

Not worth reverting while no chapter has turned the module on: the tables sit empty. If it must go, a forward migration drops what this added. Once stakes exist, the `PREDICTION` ledger rows are part of members' balances and must stay, so keep the CHECK value ([playbook](../../db-rollback-playbook.md#decision-matrix)).

```sql
drop trigger if exists chat_channels_void_predictions on chat_channels;
drop function if exists prediction_void_channel_markets();
drop function if exists void_prediction_market(uuid, uuid, uuid, boolean);
drop function if exists pay_prediction_market(uuid, uuid, uuid, boolean);
drop function if exists prediction_reverse_round(prediction_markets);
drop function if exists prediction_write_payouts(prediction_markets);
drop function if exists place_prediction_stake(uuid, uuid, uuid, uuid, int, uuid, timestamptz, int);
drop table if exists prediction_questions, prediction_stakes;
alter table prediction_markets drop constraint if exists prediction_markets_winning_answer_fk;
drop table if exists prediction_answers, prediction_markets;
alter table chapter_points_config drop column if exists prediction_max_stake;
update role_tiers set permissions = array_remove(array_remove(permissions, 'predictions:create'), 'predictions:manage');
update roles set permission_overrides = permission_overrides - 'predictions:create' - 'predictions:manage';
```
